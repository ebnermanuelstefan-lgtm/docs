# Mnemosyne

A second brain built as a memory palace: seven rooms above, one below, and a mirror at the centre.

Mnemosyne, the Titaness of memory, was mother of the nine Muses. Here, memory exists to give birth to work. The palace is organised and flexible. It is also built to think *against* you where you ask it to: Claude mirrors your voice and values, and counterweights your habits of mind.

## Start here

Answer the [intake](speculum/intake.md). Twenty questions, six of them essential, in Bulgarian, English, or French.

## Daily use

Open a Claude session on this repository and speak to the palace:

- `Capture: …` / `Запиши: …` / `Note : …` puts a thought in the Atrium.
- `Sort the atrium` files everything in the inbox.
- `Weekly review` runs the weekly ritual.

The full phrasebook is in [rituals](palace/rituals.md). Claude's operating rules are in [AGENTS.md](AGENTS.md).

## Three ways to view it

- **GitHub**, in the browser or the mobile app. It works now.
- **Obsidian**: clone the repository and open it as a vault. Point the core Templates plugin at `_templates/`.
- **Mintlify**: the repository is a [Mintlify](https://mintlify.com) site with a custom theme. Run `mint dev` to preview it locally.

## Privacy

This repository is public. Make it private before you store anything personal: on GitHub, open **Settings**, then **General**, scroll to **Danger Zone**, and choose **Change visibility**. A deployed Mintlify site is also public unless you enable authentication on your Mintlify plan.
