An ephemeris is a table of where the planets stand on each day. This one records where *you* stood. It is the only room organised by time instead of by meaning.

## Structure

| Folder | Holds | File name |
| --- | --- | --- |
| `ephemeris/daily/` | Daily notes | `2026-10-18.md` |
| `ephemeris/weekly/` | Weekly reviews | `2026-W42.md` |
| `ephemeris/lunar/` | New moon and full moon reviews | `2026-11-09-new-moon.md` |
| `ephemeris/seasonal/` | Equinox and solstice reviews | `2026-12-21-winter-solstice.md` |

The [rituals](/palace/rituals) describe each review and how to start it.
